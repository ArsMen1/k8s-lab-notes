# День 7. Разбор

Поды `checkout` Ready и с нужной меткой. Service с тем же селектором тоже есть. Они лежат в разных namespace: поды в `incidents`, Service в `default`.

Селектор не пересекает границу namespace. `kubectl get endpoints checkout` (это `default`) пустой. `kubectl -n incidents get pods` при этом выглядит здоровым, и от этого переезд особенно противный.

Короткое имя `checkout` из пода в `default` резолвится в ClusterIP сервиса в `default`. Адрес есть, бэкендов за ним нет. Имя `checkout.incidents.svc.cluster.local` сейчас тоже ни при чём: в `incidents` такого Service нет.

Починка: перенеси Service в `namespace: incidents` и удали сироту в default, иначе короткое имя в `default` продолжит указывать в пустоту.

```bash
kubectl delete svc checkout -n default
kubectl apply -f Manifests/incidents/07.yaml
kubectl -n incidents get endpoints checkout
```

Перед apply поправь namespace у Service в файле.
