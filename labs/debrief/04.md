# День 4. Разбор

Ночной файл тот же Deployment `payments-api`, но образ `nginx:definitely-the-good-hotfix`. Такого тега нет. События пода: `Failed to pull image` / `ImagePullBackOff`.

Если ты сначала применил `Manifests/payments-api/`, у Deployment две ревизии. Рабочая — предыдущая.

```bash
kubectl -n payments rollout history deploy/payments-api
kubectl -n payments rollout undo deploy/payments-api
kubectl -n payments rollout status deploy/payments-api
```

`undo` возвращает прошлый template из истории ReplicaSet. Это и есть «память», про которую писал Кирилл. Правка тега руками тоже поднимет поды, но это уже третья ревизия, а не откат.

Если история из одной ревизии — ты накатил `04.yaml` на пустое место, хорошей версии в кластере не было. Тогда undo некуда делать. Верни образ `nginx:1.27-alpine` в манифест рабочего приложения и примени `Manifests/payments-api/` заново.
