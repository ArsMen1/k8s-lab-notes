# День 1. Разбор

Поды `shop-front` живые и Ready. Service тоже есть. Связки между ними нет.

`kubectl -n incidents describe svc shop-front` внизу показывает `Endpoints: <none>`. `kubectl -n incidents get pods --show-labels` показывает метку `app.kubernetes.io/name=shop-front`. В Service селектор другой: `shop-front-v2`.

Service не ищет «поды этого Deployment». Он ищет поды с указанными метками и только в своём namespace. Контроллер не находит ни одного и пишет пустой EndpointSlice. kube-proxy некуда слать пакеты, поэтому снаружи `Connection refused`, а не страница nginx.

Починка: в `Manifests/incidents/01.yaml` поставь селектор `app.kubernetes.io/name: shop-front` и снова `kubectl apply -f Manifests/incidents/01.yaml`.

Проверка:

```bash
kubectl -n incidents get endpoints shop-front
```

В адресах должны появиться IP подов. Порт снаружи — 30081 на IP ноды. На некоторых учебных кластерах это не `localhost`, а IP из `kubectl get nodes -o wide`.
