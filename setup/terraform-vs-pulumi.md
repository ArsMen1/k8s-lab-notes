# Terraform и Pulumi: что выбрать?

Оба инструмента относятся к **Infrastructure as Code (IaC)** — подходу, при котором инфраструктуру описывают кодом и управляют ею повторяемо. Для нашей учебной лаборатории оба варианта создают один и тот же локальный kind-кластер. Это два альтернативных пути: достаточно выбрать один.

## Главное отличие

- **Terraform**: инфраструктура описывается декларативно на языке HCL. Ты задаёшь желаемые ресурсы, Terraform сравнивает их с состоянием и предлагает план изменений.
- **Pulumi**: инфраструктура описывается с помощью обычных языков программирования (в нашем примере TypeScript). Можно использовать функции, переменные, циклы и привычные конструкции языка, сохраняя IaC-модель.

## Сравнение

| Критерий | Terraform | Pulumi |
|---|---|---|
| Язык конфигурации | HCL — отдельный декларативный язык | Язык программирования, здесь TypeScript |
| Порог входа | Нужно освоить синтаксис HCL и модель Terraform | Если знаешь TypeScript/JavaScript, синтаксис может быть привычнее |
| Как описывается инфраструктура | Блоками ресурсов, переменных, outputs | Кодом, классами/функциями и ресурсами |
| Управление состоянием | Terraform state | Pulumi state |
| План изменений | `terraform plan` | Preview при `pulumi up` |
| Провайдеры | Большой каталог Terraform providers | Pulumi providers; часть интеграций использует Terraform provider bridge |
| Повторное использование | Modules | Packages, components, обычные абстракции языка |
| В нашем примере | HCL + локальный вызов kind | TypeScript + локальный вызов kind |
| Удаление ресурсов | `terraform destroy` | `pulumi destroy` |

## Пример разницы в подходе

Terraform (HCL) объявляет ресурс и его параметры:

```hcl
resource "null_resource" "kind_cluster" {
  triggers = {
    cluster_name = "k8s-lab"
  }
}
```

Pulumi (TypeScript) задаёт ресурс через объект и параметры:

```typescript
const cluster = new command.local.Command("kind-cluster", {
  create: "kind create cluster ...",
  delete: "kind delete cluster ...",
});
```

Это упрощённые иллюстрации синтаксиса, а не полный код создания кластера из лаборатории.

## Что выбрать для обучения?

**Я бы начал с Terraform.** Для Production Support полезно понять общую модель IaC: декларативное описание, state, plan, drift и безопасное применение изменений. Terraform широко встречается в инфраструктурных репозиториях, и его HCL стоит научиться читать даже если позже будешь использовать Pulumi.

Pulumi тоже стоит попробовать, особенно если нравится писать инфраструктурный код на TypeScript и хочется использовать привычные средства программирования для абстракций и логики.

### Рекомендованный маршрут

1. Подними кластер через Terraform.
2. Разберись, что Terraform хранит в state и почему перед apply нужен plan.
3. Удали кластер через Terraform.
4. Создай тот же кластер через Pulumi, сравни preview и state.
5. Выбери один инструмент для дальнейших лабораторий — смешивать оба для одного и того же кластера не нужно.

## В контексте этого репозитория

Обе реализации здесь служат учебной оболочкой для локального kind. Это не полноценное управление облачной инфраструктурой: ресурсы создаются локальным CLI, а не через облачный API.
