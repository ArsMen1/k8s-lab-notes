# Доступ из внешнего мира: LoadBalancer и Ingress

Мы уже знаем, что `Service` (ClusterIP) работает только внутри кластера. Чтобы пустить трафик снаружи, используют два подхода.

## 1. LoadBalancer (L4 - Транспортный уровень)
*(Будет дополнено)*
- Это тип `Service`, который просит облачного провайдера (или инструменты вроде MetalLB) выдать реальный внешний IP.
- Работает на уровне TCP/UDP. Он "не понимает" HTTP-пути и домены. Один внешний IP = один сервис.
- **Проблема:** Если у тебя 20 микросервисов, тебе придется купить 20 балансировщиков (что дорого).

## 2. Ingress (L7 - Прикладной уровень)
*(Будет дополнено)*
- Это "умный роутер" для HTTP/HTTPS трафика. 
- Позволяет использовать **один** внешний IP для всех сервисов, раскидывая трафик по правилам: `site.com/api` -> `api-service`, `site.com/web` -> `web-service`.
- **Важно:** Сам по себе Ingress (YAML-файл) ничего не делает. В кластере должен быть установлен **Ingress Controller** (программа, которая читает эти YAML и настраивает Nginx/Traefik).
